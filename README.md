## 🎓 Student Management System

A lightweight, command-line-based (CLI) **Student Management System** built for efficiently assessing and maintaining student records. Designed with simplicity and performance in mind, this project can run seamlessly on low-end devices and works completely offline without an internet connection.


## 🚀 Features

*   **Offline First:** Fully functional without an internet connection.
*   **Low Resource Footprint:** Optimized to run smoothly on low-end hardware and older systems.
*   **CLI Interface:** Fast, keyboard-driven interface for quick record management.
*   **CRUD Operations:** Easily add, view, update, and delete student records.
